# Hotel PMS Analytics Dashboard

A complete Hotel PMS Reporting Framework built using Metabase and SQL Server.

---

# Project Overview

This project demonstrates a real-world hotel analytics and reporting solution using:

- Metabase
- SQL Server
- SQL Queries
- KPI Dashboards
- Hospitality Reporting

The dashboards provide insights into:

- Revenue Analytics
- Occupancy Tracking
- OTA Commission Analysis
- Guest Feedback
- Front Desk Operations
- Housekeeping Monitoring
- Marketing Performance
- Finance Reporting
